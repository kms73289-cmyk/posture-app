바른자세 시작하기

Windows 설치 파일을 내려받아 내 컴퓨터에 설치해 보세요.

최신 버전 다운로드 ↓

다운로드 버튼은 GitHub Releases의 최신 설치 파일로 연결됩니다.

설치 안내

설치 파일을 다운로드한 뒤 실행해 주세요.

01. 설치 파일 다운로드

위 다운로드 버튼을 눌러 최신 Windows 설치 파일을 받습니다.

02. 설치 프로그램 실행

다운로드한 설치 파일을 실행하고 안내에 따라 설치합니다.

03. 카메라 권한 확인

자세 측정을 위해 앱의 카메라 접근을 허용하고 측정을 시작합니다.
