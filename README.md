# 바른자세 — 실시간 자세 교정 앱

웹캠 기반 실시간 자세 분석 및 교정 알림 애플리케이션입니다.
MediaPipe Pose를 활용해 목 굴곡, 머리 앞돌출, 측방 기울기, 어깨 기울기를 측정하고
자체 개발 채점 기준인 **PSI(Posture Score Index)** 로 점수를 산출합니다.

---

## 주요 기능

- 실시간 웹캠 자세 분석
- PSI 20점 만점 채점 — 낮을수록 좋은 자세
- 5초 기준 설정으로 개인별 체형·카메라 환경 보정
- 자세 등급에 따른 팝업 배너 알림 (주의 / 경고 / 위험)
- 알림 발생 시 카메라 스냅샷 자동 저장
- 알림 기록 페이지: 발생 시점 사진 + 4축 편차 차트 + 최근순/나쁜 자세 순 정렬
- 일별 캘린더 + 주간/월간 통계 차트
- 리포트 페이지: 기간별 평균 PSI, 시간대별 패턴, 등급 분포
- 히스토리 페이지: 날짜별 기록 조회
- 알림 간격 설정 (10초 / 1분 / 10분 / 30분 / 1시간)

## PSI 채점 기준

PSI는 4개 축을 독립 채점 후 가중 합산하는 방식입니다.

| 축 | 측정 항목 | 가중치 | 점수 범위 | 임계값 |
|---|---|---|---|---|
| 축1 | 목 전방 굴곡 | x2 | 1~4 | 5° / 10° / 15° |
| 축2 | 머리 앞돌출 | x1 | 1~4 | 5cm / 10cm / 15cm |
| 축3 | 측방 기울기 | x1 | 1~4 | 5° / 10° / 15° |
| 축4 | 어깨 기울어짐 | x1 | 1~4 | 3° / 6° / 9° |

**총점 = (축1 x 2) + 축2 + 축3 + 축4 — 범위: 5~20**

| PSI 점수 | 등급 | 색상 | 의미 |
|---|---|---|---|
| 5 | 완벽 | 파랑 | 이상적인 자세 |
| 6 ~ 8 | 허용 | 초록 | 양호한 자세 |
| 9 ~ 12 | 주의 | 주황 | 자세 교정 권장 |
| 13 ~ 16 | 경고 | 빨강(연) | 즉시 교정 필요 |
| 17 ~ 20 | 위험 | 빨강(진) | 거북목 위험 |

## 측정 방식

- **목 굴곡**: MediaPipe world landmarks 기반 눈 중점→입 중점 벡터의 Y-Z 성분 atan2 각도 — 기준 설정값과의 차이에 선형 보정 적용 (실제각도 = 2.0 × raw - 2.0)
- **머리 앞돌출**: 눈 사이 거리(픽셀)의 캘리브레이션 대비 변화 비율 — 선형 보정으로 실제 cm 변환 (실제cm = 42.12 × 비율 - 1.51)
- **측방 기울기**: 양쪽 눈을 잇는 선의 atan2 각도 — 머리 기울기(roll) 직접 측정
- **어깨 기울기**: 양쪽 어깨 Y좌표 차이의 atan2 각도
- 목 굴곡·측방·어깨는 deque(maxlen=20) 이동 평균, 앞돌출은 deque(maxlen=40)으로 노이즈 제거

---

## 측정값 보정

MediaPipe 측정값과 실제 물리량 사이의 오차를 실측 샘플로 선형 보정합니다.

### 목 굴곡도 보정
실측 데이터: 앱 5°→실제 8°, 앱 10°→실제 18°, 앱 15°→실제 28°

```
실제각도 = 2.0 × raw측정값 - 2.0
```

3점 완전 일치. 후신전(음수)은 보정 없이 그대로 유지.

### 앞돌출 보정
실측 데이터: 비율 0.17→5cm, 비율 0.25→10cm, 비율 0.40→15cm

```
실제cm = 42.12 × forward_dist_ratio - 1.51
```

최소제곱 피팅, 최대 오차 ±1cm.

## 기준 설정 (캘리브레이션)

PSI 채점은 절대 각도 기준이 아닌 사용자 개인의 정상 자세 대비 편차를 사용합니다.

1. 앱 시작 시 5초 카운트다운 동안 올바른 자세를 유지합니다.
2. 마지막 30프레임(약 1초)의 평균을 기준값으로 저장합니다.
3. 이후 모든 채점은 기준값과의 차이로 산출됩니다.
4. 목 굴곡·앞돌출은 기준값 차이 후 보정 적용, 측방·어깨 기울기는 절대 각도를 사용합니다.

## 성능 설계

- **모델 사전 로딩**: 앱 실행과 동시에 백그라운드에서 MediaPipe 모델 로드
- **모델 재활용**: 측정 재시작 시 기존 모델 인스턴스 재사용
- **model_complexity=0**: 앉은 자세 측정에 충분한 정확도를 유지하면서 처리 속도 향상
- **처리 속도 제어**: 창 표시 중 약 12fps, 백그라운드 측정 시 약 2fps
- **UI 갱신 주기**: 100ms (이미지 생성 비용 절감)
- **알림 이미지 지연 로딩**: 알림 기록 페이지 진입 시 카드 먼저 표시 후 이미지 순차 로드 (세마포어 3개 동시 제한)

## 사용법

1. 앱 실행 후 웹캠 앞에 바르게 앉습니다.
2. 대시보드에서 **모니터링 시작** 버튼을 누릅니다.
3. **기준 설정** (5초): 올바른 자세를 유지합니다.
4. 기준 설정 완료 후 카메라 창이 자동으로 숨겨지고 백그라운드 측정이 시작됩니다.
5. 자세가 나빠지면 화면에 경고 배너가 표시됩니다.
6. 카메라 창의 **기준 재설정** 버튼으로 기준 자세를 재설정할 수 있습니다.

---

## 데이터 저장 위치

측정 데이터는 JSON 파일로 자동 저장됩니다. 앱을 처음 실행하면 자동으로 생성됩니다.

| 항목 | 경로 |
|---|---|
| 측정 데이터 | `~/.posture_app/posture_data.json` |
| 알림 스냅샷 | `~/.posture_app/alert_images/` |
| 앱 설정 | `app_settings.json` (앱 실행 위치) |

다른 기기에서 데이터를 가져오려면 해당 경로에 JSON 파일을 복사하면 됩니다.
